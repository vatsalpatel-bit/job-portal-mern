# 🚀 NextWork

A production-ready MERN Job Portal where recruiters can post jobs and students can apply with resumes.

## 🌐 Live Demo

https://nextwork-frontend.onrender.com

## ✨ Features

- Google Authentication
- Role Based Access
- Resume Upload
- Company Management
- Job Management
- Password Reset
- Protected Routes
- Search & Filter Jobs

## 🛠 Tech Stack

Frontend
- React
- Redux Toolkit
- Tailwind CSS
- Shadcn UI
- Axios

Backend
- Node.js
- Express.js
- MongoDB
- Cloudinary

Deployment
- Render
- MongoDB Atlas
